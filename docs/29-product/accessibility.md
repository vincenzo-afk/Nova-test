# Accessibility (Product Layer)

NOVA targets WCAG 2.2 AA across desktop UI. Every screen spec in `40-screens/` must define screen-reader labels, focus order, and reduced-motion behavior. Voice interaction (`22-voice/`) is treated as a first-class accessibility surface, not a bonus feature.

Scope note: this document covers screen-reader labels, reduced-motion, and voice-as-accessibility-surface requirements. Visual styling specifics (contrast ratios, focus-state appearance) are specified in `docs/30-design/accessibility.md`, not here.
