# Keyboard Shortcuts

Command palette: configurable, default `Cmd/Ctrl+K`. Every shortcut must be discoverable in-app (not documentation-only) and must not conflict with OS-level or screen-reader shortcuts — checked against `docs/29-product/accessibility.md` (the document that specifies screen-reader/assistive-tech requirements; `docs/30-design/accessibility.md` covers visual contrast and focus-state styling, not screen-reader behavior).
