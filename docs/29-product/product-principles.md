# Product Principles

1. **Silence is a valid, often correct output.** NOVA must not narrate routine success.
2. **Every autonomous action must be reversible or previewed**, per `docs/10-security/permission-escalation.md`.
3. **The user is always one tap from seeing why NOVA did something** — every action traces to a memory or instruction.
4. **Local-first, cloud-optional** in every user-facing decision, not just the architecture.
5. **No feature ships without an edge-case and failure-state spec** — see `40-screens/`.
