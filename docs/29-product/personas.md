# Personas (Product Layer)

Builds on `docs/01-product/user-personas.md` with product-decision framing:
- **The Coordinator** — juggles calendar, email, and messaging across many threads; values NOVA surfacing conflicts before they become problems.
- **The Builder** — uses NOVA to orchestrate dev workflows and tools; values scriptability and the CLI (`27-cli/`) over chat UI.
- **The Delegator** — wants to hand off well-scoped recurring tasks and trusts NOVA incrementally as autonomy features prove reliable (`23-autonomy/`).
